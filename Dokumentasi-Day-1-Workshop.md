## Rangkuman Materi Workshop

### 1. Pengenalan Jurusan TIK

Materi pengenalan membahas visi, misi, dan arah pengembangan Jurusan TIK PNJ, termasuk kerja sama jurusan dengan industri. Materi ini memberi gambaran tentang lingkungan akademik dan bidang yang akan dipelajari.

### 2. Kurikulum dan Pengembangan Kompetensi

Peserta mempelajari kesempatan untuk mengembangkan kemampuan melalui kegiatan di luar program studi. Pengembangan kompetensi tidak hanya berlangsung di kelas, tetapi juga dapat dilakukan melalui berbagai kegiatan pendukung selama kuliah.

### 3. Prompt Engineering

Prompt Engineering membahas cara menyusun instruksi yang jelas dan tepat untuk AI. Instruksi yang baik membantu AI memahami konteks dan menghasilkan jawaban yang lebih sesuai dengan kebutuhan.

### 4. Git dan GitHub

Materi Git dan GitHub memperkenalkan pengelolaan perubahan pada file proyek menggunakan Git serta penyimpanan dan kolaborasi proyek secara online melalui GitHub. Keduanya membantu pekerjaan terdokumentasi dan lebih mudah dikelola.

## Poin Penting dan Pengetahuan Baru

- Memahami visi, misi, arah pengembangan, dan kerja sama industri Jurusan TIK PNJ.
- Mengetahui bahwa kompetensi dapat dikembangkan melalui kegiatan di luar program studi.
- Menyadari bahwa prompt yang spesifik dan jelas membantu AI memberikan jawaban yang lebih relevan.
- Mengenal fungsi Git untuk mencatat perubahan dan GitHub untuk menyimpan proyek secara online.
- Memahami pentingnya mendokumentasikan pekerjaan dan mengelola proyek secara terstruktur.

## Pendapat Pribadi tentang Day 1 Proyek Workshop

Menurut saya, Day 1 Proyek Workshop bermanfaat karena memberikan gambaran tentang jurusan, kesempatan mengembangkan kemampuan selama kuliah, dan beberapa alat yang akan digunakan dalam kegiatan akademik maupun proyek. Materi Prompt Engineering serta Git dan GitHub terasa penting untuk dipraktikkan karena dapat membantu saya bekerja lebih efektif dan menjaga pekerjaan tetap terorganisasi. Saya ingin terus berlatih agar dapat menerapkan materi tersebut dengan baik pada tugas dan proyek berikutnya.
