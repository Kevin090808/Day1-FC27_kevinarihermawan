## Deskripsi

Repository ini berisi pekerjaan dan materi latihan peserta pada kegiatan expectik hari pertama.

## Tujuan

Repository ini digunakan untuk menyimpan, mengelola, dan mendokumentasikan hasil latihan selama kegiatan expectik.

## informasi

A.pengenalan jurusan TIK
mempelajari visi, misi dan arah pengembangan jurusan TIK pnj, serta kejamsama dengan indusri

B.Kurikulum
mempelajari kesempatan mahasiswa untuk mengembangkan kemampuan melalui kegiatan di luar program studi.

C.Prompt Engineering
mempelajari cara membuat instruksi yang tepat kepada AI agar menghasilkan jawaban yang tepat dan sesuai kebutuhan.

D.Git dan GitHub
mempelajari penggunaan git untuk mengelola perubahan file dan github sebagai temppat penyimanan secara online.

## Poin-Poin Penting

- **Pengenalan Jurusan TIK:** Memahami visi, misi, arah pengembangan, dan kerja sama jurusan dengan industri.
- **Kurikulum:** Mengetahui kesempatan untuk mengembangkan kemampuan melalui kegiatan di luar program studi.
- **Prompt Engineering:** Belajar menyusun instruksi yang jelas dan tepat agar AI memberikan jawaban sesuai kebutuhan.
- **Git dan GitHub:** Memahami cara mengelola perubahan file dengan Git dan menyimpan proyek secara online menggunakan GitHub.
